## 2. What was decided a limitation

- **Squiggles under correctly spelled words the dictionary lacks** — ฟอนต์, อัปเดต,
  วิทยาศาสตรมหาบัณฑิต, Ecma, CommonMark, and code — in Word 365 for Windows, Word for macOS and
  LibreOffice Writer: the dictionary's, not the file's.
- **`--hide-spelling-errors` not honoured in Word 365 for Windows or LibreOffice Writer.** In
  Word 365 for Windows, *Hide spelling errors in this document only* is ticked under File → Options
  → Proofing — the setting was read — and the squiggles are still drawn. Word for macOS, WPS
  Writer and Google Docs show none.
- **Google Docs' lists without page numbers**: it does not update fields and must not be asked
  to (§3).

## 3. What 0.3.0 changed, as read

- **A picture fits its line (RD-01).** In `sample-options` the four pictures start at the left
  margin with no first-line indent and end inside the right margin, in all five applications.

## 4. Not read on these bytes

- The documents built with `--thai-language` and `--force-cs-whole-doc`, which are not goldens.
- Word for the web, which is not one of the five; what it draws is in `limits.md` §3 and §7.
- A Windows machine with no Thai among its languages (ADR 0038).
