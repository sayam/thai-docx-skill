# 2026-09-27 — the thesis profile joins the files a release opens

What this proves: the thesis profile's boxed caption (`--caption-matches-object`, with
`--center-images`) is in the release oracle set (ADR 0012), on a picture narrower than 3 inches and
on one narrower than the text, so `tools/package_skill.py --tag` asks for it to be read before a tag.
Until this change no golden passed `--profile thesis`, `--caption-matches-object` or
`--center-images`, and every thesis picture was wider than the text, so the box was never opened.

Environment: Python 3.13 on Linux, the tree of branch `test/oracle-thesis-variant` from `d2f6b61`.

## 1. The pictures

Two pictures, generated by a short script from rectangles, hold no text, no number and no data —
shapes and colours only — so they are synthetic content, as ADR 0040 §10 requires:

- `tests/fixtures/thesis/chart-narrow.png` — 240×160, four blue bars on a grey axis; 2.5 in at 96 dpi.
- `tests/fixtures/thesis/flow-medium.png` — 400×200, three grey boxes joined by two bars; 4.17 in at 96 dpi.

In `tests/fixtures/thesis/thesis.md` they take the place of the second use of `chart.png` (chapter 4)
and of `flow.png` (appendix ข). The figure count and every caption number stay as they were.

## 2. The variant

`sample-thesis` in `tools/oracle_set.py` builds `thesis.md` with the flags `thesis.json` stands for,
read from the profile the skill ships. Golden: `tests/golden/thesis-profile.docx`. Built on A4 with the
default margins (text width 8306 twips):

| figure | picture | caption box | indents (left = right) |
|---|---|---|---|
| รูปที่ ๒-๑, ๓-๑ | wider than the text: drawn at the text width | the text width | none |
| รูปที่ ๔-๑ | 2.5 in (3600 twips) | 3 in (4320 twips), wider than the picture | 1993 |
| รูปที่ ข-๑ | 4.17 in (6000 twips) | the picture's width | 1153 |

## 3. What moved

The four thesis goldens (`thesis-text`, `thesis-options`, `thesis-layout`, `thesis-auto`) carry the two
new pictures; `thesis-profile` is new. None of them has been opened in an application yet.
