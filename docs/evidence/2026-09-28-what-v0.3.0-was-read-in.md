the bytes it has now. After [the first reading](2026-09-27-what-v0.3.0-was-read-in.md) the goldens

## 1. What was read, and why only that

Each golden was compared with the bytes of the first reading (`bebecec`) part by part. The
intended changes were taken out on both sides, and relationship ids were replaced by the files
they name:

| golden | what changed | anything else |
|---|---|---|
| `sample-default` | `<w:noProof/>` on code · the link's tooltip | none |
| `sample-all-flags` | `<w:noProof/>` · tooltip · `<w:jc>` in table cells | none |
| `thesis-text`, `thesis-layout` | `<w:noProof/>` · two pictures' size | none, beyond the pictures and their relationships |
| `thesis-options`, `thesis-auto` | `<w:noProof/>` · `<w:jc>` in table cells · two pictures' size | none |
| `thesis-profile` | new: never opened | — |

No change reached a part of any other kind. What a diff cannot show is how the pages flow after a
picture gets shorter. So each change was read where it acts: the link's tooltip; code, in the
applications that draw proofing marks; pictures ๔-๑ and ข-๑, with the pages from chapter 4 to
the end; the table cells of the files built with `--align thai`. **`sample-thesis` was read in
full**, since its flags had never been opened together.

## 3. What was decided a limitation

- **WPS Writer flows `sample-thesis` three pages shorter than Word**: picture ๔-๑ falls on page
  11, not 14. Its own list of figures agrees with it, and `sample-options` falls on page 11 in
  every application. Word 365 for Windows is the reference, so this is recorded in `limits.md` §7
  and not changed in the bytes.

The limits of the first reading stand: squiggles under words the dictionary lacks,
`--hide-spelling-errors` not honoured in Word 365 for Windows or LibreOffice Writer, and Google
Docs' lists without page numbers.

- Word for the web, which is not one of the five.
- A Windows machine with no Thai among its languages (ADR 0038).
