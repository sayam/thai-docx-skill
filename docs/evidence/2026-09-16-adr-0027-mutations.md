# 2026-09-16 — ADR 0027 held: 26 planted defects, and the two the suite did not see

What this proves: each decision of ADR 0027 — list entries written into the field, a font
on every generated run, Latin paragraphs left-aligned under `--align thai`, and
`--chapter-title-on-new-line` with its warning — and the default line spacing of 1.0 set
the same day, is held by a test that fails when the code behind it is broken. It is the
baseline the redesign of ADR 0028 is held to: a refactor that keeps these red keeps the
behaviour.

Environment: Linux, Python 3.13.3, pytest 8.4.2, Node.js 24.15; the tree of `main` at
8048115 plus this record's test change. Content synthetic.

## Method

Each defect is one exact text replaced in `build.py` or `js/50-build.js`. For each: the
files were backed up with their sha256, the defect planted, the bundle rebuilt, the whole
suite run (`pytest -q -rf tests`, no bytecode, no cache, in its own process group), every
red test listed, the file restored, the bundle rebuilt and every hash checked before the
next. A control run at the end must be green. "Without the goldens" is the red list with
`test_sample_matches_golden_bytes` and the oracle set taken out — what holds the defect
when no golden is there to notice a changed byte.

## What run 1 found, and what changed

Run 1 had 24 red and one green: **#16, a Latin caption still spread**, stayed green. Before
writing a test, the paths from the guard to a verdict were listed (L-0003): the caption's
text is its label and number and then the Markdown's words, and every test used the Thai
labels, so a caption always held Thai and the guard never decided anything a test looked
at. Not redundant — a Latin label (`--table-label Table`) makes a caption with no Thai at
all. #17 (a Latin list entry) and #15 (two alignments on a right-aligned cell) were red only
through the goldens and the parity suite, for the same reason.

`test_thai_distributed_leaves_a_paragraph_without_thai_alone` now builds the document a
second time with `--table-label Table --toc`, a Latin heading and a list of tables, counts
the paragraphs that must be left-aligned, holds a right-aligned column to one `w:jc`, and
reads "no left alignment without the flag" as exactly that. Runs 2–4 replanted #12, #14–#17:
each red, and #15–#17 red in that test by name.
