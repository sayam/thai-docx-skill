# คู่มือใช้ thai-docx

thai-docx ช่วยทำไฟล์ Word (.docx) ภาษาไทยให้แสดงผลถูกต้อง ไม่มีเส้นหยักแดงใต้คำไทยทุกคำ
ตัดบรรทัดถูกที่ ตัวหนาและรายการแบบจุด (bullet) ใช้ได้จริง และ **ไม่เปลี่ยนข้อความต้นฉบับแม้แต่ตัวเดียว**

[English](en.md)

## ต้องใช้สกิลนี้ไหม

| กำลังทำอะไร | ใช้อะไร |
|---|---|
| พิมพ์ภาษาไทยใน Word เอง | ใช้ Word ตามปกติ Word ทำเครื่องหมายว่าเป็นภาษาไทยให้ตั้งแต่ขณะพิมพ์ ไฟล์จึงถูกต้องอยู่แล้ว |
| ขอไฟล์ Word จากผู้ช่วย AI ไม่ว่าในแชต ในโปรแกรมแก้โค้ด หรือในหน้าจอคำสั่ง | **thai-docx** ผู้ช่วยเขียนเนื้อหา แล้วคำสั่งที่มากับสกิลสร้างไฟล์ |
| เขียนโปรแกรมหรือสคริปต์ของตัวเองให้สร้าง .docx | **thai-docx** ผ่านหน้าจอคำสั่ง |
| มีไฟล์ Word อยู่แล้ว แต่ขึ้นเส้นหยักแดงหรือตัดบรรทัดผิดตำแหน่ง | **thai-docx** ตรวจให้ว่าผิดตรงไหน ไม่ว่าไฟล์นั้นมาจากโปรแกรมใด |
| คาดว่าเปิดไฟล์นั้นใน Word แล้วบันทึก Word จะซ่อมให้ | Word ไม่ซ่อม ถ้าบันทึกโดยไม่แก้อะไร ไฟล์จะกลับมาเหมือนเดิม ถ้าแก้ใน Word for the web ช่วงข้อความจะถูกเขียนใหม่เป็นภาษาอังกฤษ และยังไม่ทำเครื่องหมายภาษาไทยให้ ผู้ช่วยที่ทำงานอยู่ข้างใน Word ก็ให้ผลเดียวกัน |

ต่างกันที่ว่า **ใครเป็นคนเขียนไฟล์ และเขียนตอนไหน** Word ทำเครื่องหมายภาษาไทยถูกตั้งแต่ขณะพิมพ์
แต่แทบไม่มีโปรแกรมอื่นทำ และ Word ก็ไม่ย้อนกลับไปแก้สิ่งที่ตัวเองไม่ได้พิมพ์ นั่นคือข้อผิดพลาดที่สกิลนี้เกิดมาเพื่อแก้

## เริ่มตรงนี้

1. **ติดตั้งสกิลในแอปที่ใช้** ทำตามขั้นตอนของแอปนั้นในหน้า [ติดตั้งและเริ่มใช้](th/install.md)
2. **ขอไฟล์ Word** พิมพ์คำขอ เช่น

   ```text
   ช่วยทำไฟล์ Word สรุปการประชุมทีม มีหัวข้อและรายการเป็นข้อ ๆ
   ```

   จะได้ไฟล์ พร้อมข้อความสั้น ๆ บอกการตั้งค่าที่ใช้
3. **ปรับตามต้องการ** สั่งว่า "ขอขนาด 14" หรือ "ใส่เลขหน้า" แล้วจะได้ไฟล์ใหม่

หากไม่ได้ใช้แอป AI สร้างไฟล์เองได้ด้วยคำสั่งเดียว ดูหน้า [ใช้โดยไม่มี AI](th/command-line.md)

## สิ่งที่ต้องมี

- **เพื่อสร้างไฟล์:** Python 3.11 ขึ้นไป หรือ Node.js 22 ขึ้นไป บนเครื่องหรือในแอปที่รันสกิล
  แอปแชตที่รันโค้ดได้มี Python ให้ แต่ไม่ได้บอกรุ่น สกิลไม่ต้องต่ออินเทอร์เน็ต และไม่ต้องติดตั้งอะไรเพิ่ม
- **เพื่อเปิดไฟล์:** Word, LibreOffice, Google Docs หรือ WPS และฟอนต์ที่ไฟล์ใช้
  ฟอนต์เริ่มต้นคือ **TH Sarabun New** ถ้าไม่มี ให้ขอฟอนต์ไทยที่เครื่องมี หรือติดตั้ง Sarabun
  (ฟรีจาก Google Fonts) แล้วขอฟอนต์นั้น ถ้าจะเปิดใน Word บนเว็บ ให้ขอฟอนต์ TH SarabunPSK
  เพราะ Word บนเว็บไม่มี TH Sarabun New

## คำที่จะเจอในคู่มือ

| คำ | ความหมาย |
|---|---|
| สกิล (skill) | โฟลเดอร์ที่มีคำแนะนำและโปรแกรม ให้แอป AI โหลดไปใช้ เพื่อทำงานเรื่องหนึ่งได้ |
| ผู้ช่วย | แอป AI ที่ใช้สนทนาด้วย เช่น Claude หรือ ChatGPT |
| โฟลเดอร์ | ที่เก็บไฟล์ในเครื่อง เทียบได้กับแฟ้มเอกสาร "วางไฟล์ไว้ในโฟลเดอร์" หมายถึงโฟลเดอร์ที่ผู้ช่วยทำงานอยู่ ในแอปแชตคือแนบในแชต |
| Markdown | ข้อความธรรมดาที่ใช้สัญลักษณ์บอกรูปแบบ เช่น `#` คือหัวข้อ `**คำ**` คือตัวหนา |
| การตั้งค่า | สิ่งที่กำหนดหน้าตาไฟล์ เช่น ฟอนต์ ขนาด กระดาษ เลขหน้า |
| โปรไฟล์ (profile) | ชุดการตั้งค่าที่บันทึกไว้ใช้ซ้ำ |
| ตัวเลือก (flag) | คำสั่งเสริมที่พิมพ์ต่อท้ายคำสั่ง เช่น `--size 14` |
| อักษรซับซ้อน (complex script) | ตัวอักษรที่โปรแกรมต้องจัดรูปเป็นพิเศษ เช่น ไทย ไฟล์ Word ต้องบอกว่าข้อความไหนเป็นอักษรแบบนี้ |
| grill | โหมดที่ผู้ช่วยถามการตั้งค่าก่อนสร้างไฟล์ |
| ฟิลด์ | ส่วนในไฟล์ Word ที่ Word คำนวณเอง เช่น เลขหน้าในสารบัญ |
