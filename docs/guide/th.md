# คู่มือใช้ thai-docx ทีละขั้น

คู่มือนี้บอกวิธีใช้ thai-docx ตั้งแต่ขอไฟล์ Word ง่าย ๆ ไปจนถึงแก้ชุดการตั้งค่าที่เคยบันทึกไว้
อ่านเฉพาะหัวข้อที่อยากทำก็ได้

[English version](en.md)

## thai-docx คืออะไร

thai-docx เป็น **สกิล (skill)** คือความรู้เสริมที่ติดตั้งให้ผู้ช่วย AI เช่น Claude
เมื่อเราขอไฟล์ Word ที่มีภาษาไทย ผู้ช่วยจะใช้สกิลนี้สร้างไฟล์ให้

ไฟล์ Word ภาษาไทยที่โปรแกรมทั่วไปสร้าง มักมีปัญหาแบบนี้

- มีเส้นหยักสีแดงใต้คำไทยทุกคำ
- ตัดบรรทัดกลางประโยคแปลก ๆ
- ตัวหนาไม่หนา หัวข้อย่อยไม่ขึ้นจุด

thai-docx แก้ปัญหาเหล่านี้ให้ และ **ไม่เปลี่ยนข้อความของเราแม้แต่ตัวเดียว**

คำที่จะเจอในคู่มือนี้

| คำ | ความหมาย |
|---|---|
| Markdown | วิธีเขียนข้อความธรรมดาที่ใช้สัญลักษณ์บอกรูปแบบ เช่น `#` คือหัวข้อ, `**คำ**` คือตัวหนา |
| การตั้งค่า | สิ่งที่กำหนดหน้าตาไฟล์ เช่น ฟอนต์ ขนาดตัวอักษร กระดาษ เลขหน้า |
| โปรไฟล์ (profile) | ชุดการตั้งค่าที่บันทึกไว้ใช้ซ้ำ เหมือนสูตรที่จดไว้ |
| grill | โหมดที่ให้ผู้ช่วยถามการตั้งค่าเราก่อนสร้างไฟล์ |
| โฟลเดอร์ | ที่เก็บไฟล์ในเครื่อง เหมือนแฟ้มเอกสาร |
| โปรเจกต์ | โฟลเดอร์ของงานชิ้นหนึ่ง ที่ผู้ช่วยกำลังทำงานอยู่ |
| ฟิลด์ | ส่วนในไฟล์ Word ที่ Word คำนวณให้เอง เช่น เลขหน้าในสารบัญ |
| คำเตือน | ข้อความบอกให้รู้ว่ามีบางอย่างควรดู แต่ไฟล์ยังสร้างได้ |

## ก่อนเริ่ม: ติดตั้งสกิล

ดาวน์โหลดไฟล์ `thai-docx-<เลขรุ่น>.zip` จากหน้า
[Releases](https://github.com/sayam/thai-docx-skill/releases) แล้วเลือกตามโปรแกรมที่ใช้

- **Claude Code** (โปรแกรมบนเครื่อง): แตกไฟล์ zip ไว้ในโฟลเดอร์ `~/.claude/skills/`
  จะได้โฟลเดอร์ `~/.claude/skills/thai-docx/` ถ้าอยากใช้แค่ในโปรเจกต์เดียว ให้แตกไว้ใน
  `.claude/skills/` ของโปรเจกต์นั้น
- **Claude บนเว็บหรือแอป**: อัปโหลดไฟล์ zip ในหน้าตั้งค่าที่รับสกิล
- **แอปแชตอื่นที่ไม่มีสกิล แต่รันโปรแกรม Python ได้**: ทำตาม
  [PROMPT.md](https://github.com/sayam/thai-docx-skill/blob/main/PROMPT.md)

เครื่องต้องมี Python 3.11 ขึ้นไป หรือ Node.js อย่างใดอย่างหนึ่ง สกิลไม่ต้องต่ออินเทอร์เน็ต
และไม่ต้องติดตั้งอะไรเพิ่ม

สำหรับการใช้ครั้งแรก เครื่องที่จะเปิดไฟล์ควรมีฟอนต์ **TH Sarabun New**
ถ้าไม่มี ให้ขอฟอนต์อื่นที่มีภาษาไทย เช่น Sarabun (ดูสถานการณ์ที่ 3)

## สถานการณ์ที่ 1: ขอไฟล์ Word แบบง่ายที่สุด

**ใช้เมื่อ** อยากได้เอกสารเร็ว ๆ และยังไม่สนใจเรื่องรูปแบบ

1. พิมพ์บอกผู้ช่วยว่าอยากได้เอกสารเรื่องอะไร

   ```text
   ช่วยทำไฟล์ Word สรุปวิธีขอหนังสือเดินทางแบบสั้น ๆ มีหัวข้อ รายการเอกสารที่ต้องใช้ และตารางค่าธรรมเนียม
   ```

2. ผู้ช่วยจะเขียนเนื้อหา แล้วสร้างไฟล์ทันที **ไม่ถามอะไรก่อน**
3. ผู้ช่วยจะบอกชื่อไฟล์ และการตั้งค่าที่ใช้ เช่น

   > สร้าง `passport.docx` แล้ว — ฟอนต์ TH Sarabun New 16 pt, กระดาษ A4, ขอบซ้าย 1.5 นิ้ว
   > ด้านอื่น 1 นิ้ว ปรับค่าใดก็ได้

4. เปิดไฟล์ด้วย Word ได้เลย

การตั้งค่าเริ่มต้น (ถ้าไม่ได้ขออะไร)

| เรื่อง | ค่าเริ่มต้น |
|---|---|
| ฟอนต์ | TH Sarabun New ขนาด 16 pt |
| กระดาษ | A4 แนวตั้ง |
| ขอบกระดาษ | ซ้าย 1.5 นิ้ว ด้านอื่น 1 นิ้ว |
| ระยะบรรทัด | 1 เท่า |
| การจัดย่อหน้า | ชิดซ้าย |
| สารบัญ, เลขหน้า | ไม่มี |

## สถานการณ์ที่ 2: มีไฟล์ Markdown อยู่แล้ว

**ใช้เมื่อ** เขียนเนื้อหาไว้เองแล้ว อยากให้กลายเป็นไฟล์ Word

1. วางไฟล์ เช่น `report.md` ไว้ในโฟลเดอร์ที่ผู้ช่วยทำงาน (หรืออัปโหลดในแชต)
2. พิมพ์

   ```text
   ช่วยทำ report.md เป็นไฟล์ Word ชื่อ report.docx
   ```

3. ผู้ช่วยจะใช้ไฟล์ของเรา **ตามที่เขียนไว้เป๊ะ ๆ** แล้วสร้าง `report.docx`

สิ่งที่เขียนใน Markdown ได้ เช่น

```markdown
# หัวข้อใหญ่

## หัวข้อย่อย

ข้อความธรรมดา **ตัวหนา** *ตัวเอียง*

- รายการที่หนึ่ง
- รายการที่สอง

| สินค้า | ราคา |
|---|---|
| ปากกา | 10 |

![ภาพประกอบ](chart.png)
```

ข้อควรรู้

- รูปต้องเป็น PNG หรือ JPEG และอยู่ในโฟลเดอร์เดียวกับไฟล์ Markdown (หรือโฟลเดอร์ย่อย)
- เขียนภาษาไทยตามปกติ **ไม่ต้องเว้นวรรคระหว่างคำ** ขึ้นบรรทัดใหม่กลางประโยคไทยได้
- ถ้ามีสิ่งที่สกิลอ่านไม่ได้ เช่น แท็ก HTML แปลก ๆ สกิลจะบอกว่า **อยู่บรรทัดไหน** ให้แก้บรรทัดนั้น

## สถานการณ์ที่ 3: ได้ไฟล์แล้ว อยากเปลี่ยนการตั้งค่า

**ใช้เมื่อ** ไฟล์ออกมาแล้ว แต่อยากได้ฟอนต์ ขนาด หรือเลขหน้าแบบอื่น

1. พิมพ์บอกสิ่งที่อยากเปลี่ยน ในแชตเดิม

   ```text
   ขอฟอนต์ Sarabun ขนาด 14 และใส่เลขหน้าตรงกลางด้านล่าง
   ```

2. ผู้ช่วยจะสร้างไฟล์ใหม่ โดยเปลี่ยนเฉพาะสิ่งที่ขอ ที่เหลือเหมือนเดิม
3. ผู้ช่วยจะบอกการตั้งค่าใหม่ ให้ตรวจว่าตรงกับที่ขอ

ตัวอย่างสิ่งที่ขอเปลี่ยนได้

| อยากได้ | พูดกับผู้ช่วยว่า |
|---|---|
| ฟอนต์อื่น | "ขอฟอนต์ Sarabun" |
| ตัวอักษรเล็กลง | "ขนาด 14" |
| กระดาษ Letter หรือ F14 | "ใช้กระดาษ F14" |
| กระดาษแนวนอน | "ขอแนวนอน" |
| ขอบกระดาษ 1 นิ้วทุกด้าน | "ขอบ 1 นิ้วทุกด้าน" |
| ย่อหน้าบรรทัดแรก | "ย่อหน้า 0.5 นิ้ว" |
| บรรทัดห่างขึ้น | "ระยะบรรทัด 1.5" |
| จัดข้อความเต็มบรรทัดแบบไทย | "จัดกระจายแบบไทย" |
| สารบัญ | "ใส่สารบัญ" |
| เลขหน้า | "ใส่เลขหน้า" (มุมขวาบน) หรือ "เลขหน้ากลางล่าง" |
| ไม่มีเลขหน้าหน้าแรก | "หน้าแรกไม่ต้องมีเลขหน้า" |
| เลขไทย | "ใช้เลขไทย" (เปลี่ยนเฉพาะเลขหน้า เลขรายการ เลขเชิงอรรถ ไม่เปลี่ยนตัวเลขในเนื้อความ) |
| ข้อความหัวกระดาษ/ท้ายกระดาษ | "หัวกระดาษเขียนว่า เอกสารลับ" |
| ซ่อนเส้นหยักตรวจคำ | "ซ่อนเส้นหยัก" (จะซ่อนคำที่สะกดผิดจริงด้วย) |

รายการการตั้งค่าทั้งหมด:
[references/settings.md](https://github.com/sayam/thai-docx-skill/blob/main/skills/thai-docx/references/settings.md)

## สถานการณ์ที่ 4: บอกการตั้งค่าตั้งแต่แรก

**ใช้เมื่อ** รู้อยู่แล้วว่าอยากได้แบบไหน

1. ใส่การตั้งค่าไว้ในคำขอเลย

   ```text
   ทำ input.md เป็นไฟล์ Word ชื่อ output.docx ขนาดตัวอักษร 14 กระดาษ letter ขอบทุกด้าน 1 นิ้ว ย่อหน้าบรรทัดแรก 0.5 นิ้ว ระยะบรรทัด 1.5
   ```

2. ผู้ช่วยจะสร้างไฟล์ทันที แล้วบอกการตั้งค่าที่ใช้
3. **ตรวจว่าผู้ช่วยบอกครบทุกข้อที่ขอ** ถ้าขาดข้อไหน ให้บอกซ้ำ

## สถานการณ์ที่ 5: อยากให้ผู้ช่วยถามก่อนสร้าง (โหมด grill)

**ใช้เมื่อ** ยังไม่แน่ใจว่าควรตั้งค่าอย่างไร อยากเลือกจากตัวเลือก

1. ใส่คำว่า **`thai-docx grill`** ไว้ในข้อความ (ต้องมีคำนี้ ผู้ช่วยจึงจะถาม)

   ```text
   thai-docx grill ช่วยทำเอกสาร Word เรื่องกำหนดการประชุมทีมประจำเดือนให้หน่อย
   ```

2. ผู้ช่วยจะถาม 9 ข้อ แต่ละข้อมีตัวเลือก a, b, c, d
   - ฟอนต์
   - ขนาดตัวอักษร
   - กระดาษและขอบ
   - การจัดย่อหน้า
   - ย่อหน้าบรรทัดแรก
   - สารบัญ
   - เลขหน้า
   - เส้นหยักตรวจคำสะกด
   - บันทึกการตั้งค่าไว้ใช้ครั้งหน้าหรือไม่
3. ถ้าผู้ช่วยแสดงเป็นกล่องให้กดเลือก (เช่นใน Claude Code) ก็กดเลือกได้เลย
   ถ้าถามเป็นข้อความ ให้ตอบสั้น ๆ เป็นเลขข้อกับตัวอักษร ข้อที่ไม่ตอบจะใช้ตัวเลือกเดิม

   ```text
   4b 7b ที่เหลือใช้ค่าเดิม
   ```

4. ผู้ช่วยจะสร้างไฟล์ตามคำตอบ

ข้อควรรู้

- ถ้าไม่พิมพ์ `thai-docx grill` ผู้ช่วยจะ **ไม่ถาม** และสร้างไฟล์ทันที
- ถ้าผู้ช่วยสร้างไฟล์โดยไม่ถาม ทั้งที่พิมพ์ `thai-docx grill` แล้ว ให้พิมพ์ข้อความเดิมอีกครั้ง

## สถานการณ์ที่ 6: อยากได้หัวข้อสวย ๆ

**ใช้เมื่อ** อยากให้หัวข้อมีสี ขนาด หรือการจัดวางพิเศษ

1. บอกผู้ช่วยว่าอยากได้หัวข้อแบบไหน

   ```text
   ทำ notice.md เป็นไฟล์ Word หัวข้อใหญ่สุดสีน้ำเงินเข้ม จัดกึ่งกลาง ขนาด 22 pt หัวข้อรองขีดเส้นใต้คู่
   ```

2. ผู้ช่วยจะเขียนการตั้งค่าหัวข้อไว้ส่วนบนสุดของไฟล์ Markdown แบบนี้

   ```markdown
   ---
   heading-1: font-size: 22pt; color: #1F4E79; text-align: center
   heading-2: text-decoration: underline double
   ---
   ```

3. เลขหัวข้อ เช่น "บทที่ 1" หรือ "1.1" จะมีขนาด ฟอนต์ และสีเดียวกับหัวข้อ

## สถานการณ์ที่ 7: ทำรายงานหรือวิทยานิพนธ์

**ใช้เมื่อ** เอกสารมีหน้าปก บทคัดย่อ สารบัญ บทที่ 1, 2, 3 ตาราง รูป และภาคผนวก

1. บอกผู้ช่วยสิ่งที่ต้องมีให้ครบ

   ```text
   ช่วยทำ draft.md เป็นไฟล์ Word วิทยานิพนธ์ชื่อ thesis.docx มีหน้าปก บทคัดย่อ สารบัญ สารบัญตาราง บทที่มีเลขบท ชื่อตารางแบบ ตารางที่ 1-1 ภาคผนวก ก ข ค และเลขหน้า ห้ามแก้เนื้อหา
   ```

2. ผู้ช่วยจะใส่ **ป้ายบอกส่วน** ลงในไฟล์ Markdown ป้ายเหล่านี้ไม่แสดงในไฟล์ Word

   | ป้าย | ความหมาย |
   |---|---|
   | `<!-- front -->` | ส่วนหน้า เช่น บทคัดย่อ สารบัญ (เลขหน้า ก ข ค) |
   | `<!-- chapters -->` | ส่วนเนื้อหา หัวข้อ `#` กลายเป็น "บทที่ 1", "บทที่ 2" |
   | `<!-- back -->` | ส่วนท้าย เช่น บรรณานุกรม |
   | `<!-- appendices -->` | ภาคผนวก หัวข้อ `#` กลายเป็น "ภาคผนวก ก", "ภาคผนวก ข" |
   | `<!-- toc -->` | ตรงนี้ใส่สารบัญ |
   | `<!-- list-of-tables -->` | ตรงนี้ใส่สารบัญตาราง |
   | `<!-- list-of-figures -->` | ตรงนี้ใส่สารบัญภาพ |

3. ชื่อตารางเขียน `Table: ชื่อตาราง` เป็นย่อหน้า **ก่อนตาราง** ชื่อรูปเขียน
   `Figure: ชื่อรูป` เป็นย่อหน้า **หลังรูป** ทั้งสองแบบให้เว้นบรรทัดว่างหนึ่งบรรทัดคั่นไว้
   ในไฟล์ Word จะกลายเป็น "ตารางที่ 1-1 ชื่อตาราง" และ "รูปที่ 1-1 ชื่อรูป"
4. เปิดไฟล์แล้ว ถ้าสารบัญยังไม่มีเลขหน้า ให้กดอัปเดตฟิลด์ (ใน Word กด Ctrl+A แล้ว F9)

ข้อควรรู้

- สารบัญมีรายการให้ตั้งแต่เปิดไฟล์ แต่ **เลขหน้าในสารบัญ** จะมาหลังอัปเดตฟิลด์
- ถ้าขอสิ่งที่เอกสารไม่มี เช่น เปลี่ยนคำว่า "บทที่" แต่ไม่มีส่วน `<!-- chapters -->`
  สกิลจะเตือนว่า "changed nothing" (ไม่มีผลอะไร)

## สถานการณ์ที่ 8: บันทึกการตั้งค่าเป็นโปรไฟล์

**ใช้เมื่อ** ได้การตั้งค่าที่ชอบแล้ว อยากใช้อีกโดยไม่ต้องบอกซ้ำ

**วิธีที่ 1: ตอนตอบคำถาม grill** ข้อสุดท้ายถามว่าจะบันทึกไหม ตอบ b แล้วตั้งชื่อ

```text
1c 9b ชื่อ myreport
```

**วิธีที่ 2: บอกตรง ๆ**

```text
บันทึกการตั้งค่านี้เป็นโปรไฟล์ชื่อ thesis: ขนาด 15 จัดกระจายแบบไทย ใส่เลขหน้ากลางล่าง
```

ผู้ช่วยจะบอกชื่อโปรไฟล์ และที่เก็บไฟล์

- **Claude Code**: เก็บไว้ที่ `~/.thai-docx/profiles/ชื่อ.json` ใช้ได้ทุกโปรเจกต์
  ถ้าพูดว่า "บันทึกไว้ในโปรเจกต์นี้" จะเก็บใน `.thai-docx/profiles/` ของโปรเจกต์
- **Claude บนเว็บหรือแอป**: ผู้ช่วยจะให้ไฟล์ `.json` มา **เก็บไฟล์นี้ไว้เอง**
  ครั้งหน้าให้แนบไฟล์นี้มาด้วย

ชื่อโปรไฟล์ใช้ตัวอักษรอังกฤษ ตัวเลข `-` และ `_` ได้ ห้ามมีช่องว่าง

## สถานการณ์ที่ 9: ใช้โปรไฟล์ที่บันทึกไว้

1. พิมพ์ชื่อโปรไฟล์ในคำขอ

   ```text
   ทำ chapter2.md เป็นไฟล์ Word ใช้โปรไฟล์ thesis
   ```

2. ผู้ช่วยจะสร้างไฟล์ด้วยการตั้งค่าในโปรไฟล์ แล้วบอกว่าใช้โปรไฟล์ไหน
3. อยากเปลี่ยนบางอย่างแค่ครั้งนี้ ก็บอกเพิ่มได้ สิ่งที่บอกเพิ่มจะชนะโปรไฟล์

   ```text
   ใช้โปรไฟล์ thesis แต่ครั้งนี้ขอขนาด 18
   ```

อยากรู้ว่ามีโปรไฟล์อะไรบ้าง

```text
มีโปรไฟล์ thai-docx อะไรบ้าง
```

## สถานการณ์ที่ 10: แบ่งปันโปรไฟล์ให้คนอื่น หรือรับของคนอื่น

**ส่งให้เพื่อน**

1. พิมพ์

   ```text
   ส่งออกโปรไฟล์ thesis เป็นไฟล์ให้หน่อย
   ```

2. จะได้ไฟล์ `thesis.json` ส่งไฟล์นี้ให้เพื่อนทางไหนก็ได้ เช่น อีเมล LINE

**รับจากเพื่อน**

1. วางไฟล์ `.json` ที่ได้รับไว้ในโฟลเดอร์ที่ผู้ช่วยทำงาน หรือแนบในแชต
2. พิมพ์

   ```text
   นำเข้าโปรไฟล์จากไฟล์ thesis.json
   ```

3. ถ้าอยากตั้งชื่อใหม่ ให้บอกชื่อไปด้วย เช่น "นำเข้าเป็นชื่อ school-thesis"

สกิลจะตรวจไฟล์ก่อนเสมอ ไฟล์โปรไฟล์มีได้แค่การตั้งค่า ถ้ามีอย่างอื่นจะไม่รับ

## สถานการณ์ที่ 11: แก้โปรไฟล์โดยให้ผู้ช่วยถาม

**ใช้เมื่อ** มีโปรไฟล์อยู่แล้ว อยากปรับบางอย่าง แล้วบันทึกเป็นชื่อใหม่
(ของเดิมยังอยู่)

1. พิมพ์ `thai-docx grill จาก` ชื่อโปรไฟล์เดิม `บันทึกเป็น` ชื่อใหม่

   ```text
   thai-docx grill จาก thesis บันทึกเป็น thesis-v2 ช่วยทำ input.md เป็นไฟล์ Word ชื่อ output.docx
   ```

   ภาษาอังกฤษก็ได้

   ```text
   thai-docx grill from thesis save to thesis-v2
   ```

2. ผู้ช่วยจะถามทีละข้อเหมือนสถานการณ์ที่ 5 แต่ **ตัวเลือกที่ตรงกับโปรไฟล์เดิมจะมีป้าย "(ตอนนี้)"**
3. ตอบเฉพาะข้อที่อยากเปลี่ยน ข้อที่ไม่ตอบจะเหมือนโปรไฟล์เดิม

   ```text
   2b 6a ที่เหลือเหมือนเดิม
   ```

4. ผู้ช่วยจะบันทึกโปรไฟล์ใหม่ `thesis-v2` แล้วสร้างไฟล์ด้วยโปรไฟล์นั้น

อยากให้ถามแค่บางข้อ ใช้คำว่า `เฉพาะ` แล้วตามด้วยชื่อข้อ คั่นด้วยจุลภาค

```text
thai-docx grill จาก thesis บันทึกเป็น thesis-v3 เฉพาะ size,toc
```

ชื่อข้อที่ใช้ได้: `font` (ฟอนต์), `size` (ขนาด), `paper` (กระดาษและขอบ), `align` (การจัดย่อหน้า),
`indent` (ย่อหน้าบรรทัดแรก), `toc` (สารบัญ), `page-numbers` (เลขหน้า), `squiggles` (เส้นหยัก),
`save` (บันทึก) หรือใช้เลขข้อ 1 ถึง 9 แทนก็ได้

ข้อควรรู้

- คำว่า `จาก`, `บันทึกเป็น`, `เฉพาะ` ต้องอยู่ **ต่อจาก `thai-docx grill` ทันที**
- ถ้าไม่มีโปรไฟล์ชื่อที่บอก ผู้ช่วยจะแจ้งว่าไม่พบ ให้ตรวจชื่ออีกครั้ง

## สถานการณ์ที่ 12: แก้โปรไฟล์แบบบอกตรง ๆ ไม่ต้องถาม

**ใช้เมื่อ** รู้แน่แล้วว่าจะเปลี่ยนอะไร

```text
สร้างโปรไฟล์ thesis-v2 จากโปรไฟล์ thesis แต่เปลี่ยนเป็นขนาด 14 และไม่เอาสารบัญ
```

ผู้ช่วยจะบันทึกโปรไฟล์ใหม่ที่เหมือนเดิมทุกอย่าง ยกเว้นสิ่งที่บอก

การ **เอาออก** เช่น "ไม่เอาสารบัญ" "ไม่เอาเลขหน้า" ทำได้ สกิลจะคืนค่านั้นเป็นค่าเริ่มต้น
(ผู้ช่วยใช้คำสั่ง `--default` ให้เอง)

## สถานการณ์ที่ 13: ตรวจไฟล์ Word ภาษาไทยที่มีอยู่แล้ว

**ใช้เมื่อ** มีไฟล์ Word จากที่อื่น แล้วมีเส้นหยัก ตัดบรรทัดแปลก หรือตัวหนาไม่หนา

1. วางไฟล์ไว้ในโฟลเดอร์ที่ผู้ช่วยทำงาน หรือแนบในแชต
2. พิมพ์

   ```text
   ช่วยตรวจ report.docx หน่อยว่าทำไมมีเส้นหยักแดงใต้คำไทยทุกคำ
   ```

3. ผู้ช่วยจะอธิบายว่าเจอปัญหาอะไร และแต่ละปัญหาทำให้เห็นอะไรในไฟล์

ข้อควรรู้: สกิล **ตรวจอย่างเดียว ไม่ซ่อมไฟล์** ถ้ามีเนื้อหาอยู่ ให้สร้างไฟล์ใหม่ด้วยสถานการณ์ที่ 1 หรือ 2

## เมื่อมีปัญหา

| เจออะไร | หมายความว่า | ทำอย่างไร |
|---|---|---|
| ผู้ช่วยบอกว่ามี **คำเตือน (warning)** | ไฟล์สร้างเสร็จแล้ว แต่มีบางอย่างควรรู้ เช่น ฟอนต์ไม่มีภาษาไทย หรือการตั้งค่าไม่มีผล | อ่านคำเตือน แล้วแก้ถ้าจำเป็น |
| ผู้ช่วยบอกว่ามี **ข้อผิดพลาดที่บรรทัด...** | สกิลอ่าน Markdown บรรทัดนั้นไม่ได้ ยังไม่ได้สร้างไฟล์ | แก้บรรทัดนั้น เช่น ลบแท็ก HTML แล้วสั่งใหม่ |
| ผู้ช่วยบอกว่ามี **findings** | เป็นข้อบกพร่องของสกิลเอง ไม่ได้สร้างไฟล์ | แจ้งผู้ดูแลสกิลที่หน้า [Issues](https://github.com/sayam/thai-docx-skill/issues) |
| ในไฟล์ Word ตัวอักษรไทยเป็นฟอนต์แปลก | เครื่องไม่มีฟอนต์ที่ตั้งไว้ | ติดตั้งฟอนต์นั้น หรือขอฟอนต์อื่น (สถานการณ์ที่ 3) |
| สารบัญไม่มีเลขหน้า | ยังไม่ได้อัปเดตฟิลด์ | ใน Word กด Ctrl+A แล้ว F9 |
| ผู้ช่วยไม่ถามคำถาม ทั้งที่อยากให้ถาม | ข้อความไม่มี `thai-docx grill` | พิมพ์ใหม่ให้มีคำนี้ |
