# แก้ปัญหา

ข้อกำหนดทั้งหมดรวมไว้ที่เดียว — สกิลนี้รับประกันอะไร เปิดไฟล์แล้วต้องทำอะไรเอง อะไรที่ไม่ไล่เลขให้เมื่อแก้ไฟล์
และห้าแอปต่างกันตรงไหน: `skills/thai-docx/references/limits.md`

ค้นหาอาการที่พบในคอลัมน์ซ้าย

[หน้าแรกของคู่มือ](../th.md) · [English](../en/troubleshooting.md)

## ตอนติดตั้ง

| เจออะไร | เพราะอะไร | ทำอย่างไร |
|---|---|---|
| แอปไม่แสดง thai-docx ในรายการ | วางโฟลเดอร์ผิดที่ หรือซ้อนลึกไปหนึ่งชั้น | ที่อยู่ไฟล์ต้องลงท้าย `skills/thai-docx/SKILL.md` ไม่ใช่ `skills/thai-docx/thai-docx/SKILL.md` แล้วเปิดแอปใหม่ |
| แอป Claude ไม่รับไฟล์ที่อัปโหลด | ยังไม่เปิดการรันโค้ด องค์กรปิดสกิลที่ผู้ใช้สร้างเอง หรือเป็นรุ่น 0.1.0 ซึ่งคำอธิบายสกิลยาวเกินที่แอปรับ | เปิด **Code execution and file creation** ถามผู้ดูแลองค์กร หรือดาวน์โหลดรุ่นที่ใหม่กว่า 0.1.0 ([แอป Claude](install.md#แอป-claude)) หากยังไม่ได้ผล [แจ้งที่หน้า Issues](https://github.com/sayam/thai-docx-skill/issues) พร้อมข้อความที่ปรากฏ |
| แอป Gemini ไม่รับไฟล์ที่อัปโหลด | Google ให้ `SKILL.md` อยู่ในโฟลเดอร์หลักของ zip | zip ของข้างในโฟลเดอร์ `thai-docx` แล้วอัปโหลดใหม่ ([แอป Gemini](install.md#แอป-gemini)) |
| ChatGPT ขึ้นว่า **Needs Review** หรือ **Blocked** | ที่ทำงานตั้งให้ตรวจสกิลที่อัปโหลด | ถามผู้ดูแลระบบของที่ทำงาน |
| ผู้ช่วยบอกว่าไม่มี Python หรือ Node.js หรือสร้างไฟล์ไม่ได้เพราะ Python ผิดพลาด | เครื่องไม่มีทั้งสองอย่าง หรือ Python เก่ากว่า 3.11 | ติดตั้ง Python 3.11 ขึ้นไป หรือ Node.js 22 ขึ้นไป |
| ผู้ช่วยสร้างไฟล์ Word ด้วยวิธีของตัวเอง ไม่ใช้สกิล | ผู้ช่วยไม่ได้เลือกสกิลนี้ | ขึ้นต้นข้อความด้วย `/thai-docx` (Claude Code, Copilot, Cursor), `$thai-docx` (Codex) หรือ "ใช้สกิล thai-docx" |

## ตอนสร้างไฟล์

| เจออะไร | เพราะอะไร | ทำอย่างไร |
|---|---|---|
| มี **คำเตือน (warning)** | ไฟล์สร้างแล้ว แต่มีจุดที่ควรตรวจสอบ เช่น ฟอนต์ไม่มีตัวอักษรไทย หรือการตั้งค่าไม่มีผล | อ่านคำเตือน แล้วปรับคำขอหากจำเป็น |
| มี **ข้อผิดพลาดที่บรรทัด ...** | Markdown บรรทัดนั้นมีสิ่งที่สกิลไม่รับ เช่น แท็ก HTML ยังไม่สร้างไฟล์ | แก้บรรทัดนั้น แล้วสั่งใหม่ |
| มี **findings** | ข้อบกพร่องของสกิลเอง ยังไม่สร้างไฟล์ | โปรดแจ้งที่หน้า [Issues](https://github.com/sayam/thai-docx-skill/issues) |
| รูปใช้ไม่ได้ | ไม่ใช่ PNG หรือ JPEG, เป็นรูปจากอินเทอร์เน็ต หรืออยู่นอกโฟลเดอร์ของไฟล์ Markdown | ใช้ PNG หรือ JPEG ในโฟลเดอร์นั้น หรือระบุโฟลเดอร์ที่เก็บรูป |
| การตั้งค่าที่ขอไม่อยู่ในคำตอบ | ผู้ช่วยตกหล่น | ขอการตั้งค่านั้นอีกครั้ง |
| ผู้ช่วยไม่ถามคำถาม | ข้อความไม่มีคำว่า `thai-docx grill` (ระหว่างสองคำใช้ได้ทั้งขีดกลาง ขีดล่าง และเว้นวรรค) | ส่งข้อความใหม่โดยมีคำนี้ |
| `'' is not a question` | มีช่องว่างหลังจุลภาค เช่น `เฉพาะ size, toc` | เขียนติดกัน `เฉพาะ size,toc` |
| แอปแชตหาโปรไฟล์ที่บันทึกไว้ไม่เจอ | แอปแชตลืมไฟล์เมื่อจบแชต | แนบไฟล์ `.json` ของโปรไฟล์ |
| บันทึกโปรไฟล์แล้วต้องขออนุญาต หรือบันทึกไม่ได้ | แอปไม่ให้ผู้ช่วยเขียนไฟล์นอกโปรเจกต์ | กดอนุญาต หรือสั่งว่า "บันทึกไว้ในโปรเจกต์นี้" |

## ตอนเปิดไฟล์

| เจออะไร | เพราะอะไร | ทำอย่างไร |
|---|---|---|
| ตัวอักษรไทยแสดงผิดฟอนต์ | เครื่องไม่มีฟอนต์ที่ไฟล์ใช้ | ติดตั้งฟอนต์นั้น หรือขอฟอนต์ที่เครื่องมี |
| สารบัญ สารบัญตาราง หรือสารบัญภาพไม่มีเลขหน้า | ยังไม่ได้อัปเดตฟิลด์ | Word: กด Ctrl+A แล้ว F9 · LibreOffice: Ctrl+Shift+F9 · WPS: **References > Update** |
| ใน WPS Writer เลข บทที่ หรือ ภาคผนวก แสดงผิดเพี้ยน | เคยพบครั้งหนึ่งเมื่อ 19 กันยายน 2569 ลองซ้ำเมื่อ 23 กันยายน 2569 ไม่เกิดอีก และยังไม่ทราบสาเหตุ | ช่วย[แจ้งที่หน้า Issues](https://github.com/sayam/thai-docx-skill/issues) พร้อมภาพหน้าจอ ระหว่างนี้เปิดด้วย Word |
| ใน WPS Writer สระอำวางผิดตำแหน่ง | ไฟล์นี้สร้างด้วย `--thai-language` และ WPS จัดการเครื่องหมายภาษาไทยที่ตัวเลือกนั้นเขียนไว้ไม่ถูก | สร้างใหม่โดยไม่ใส่ตัวเลือกนั้น แล้ว Word จะเอาภาษาจากเครื่องผู้อ่านแทน ซึ่งเครื่องที่พิมพ์ไทยได้มีอยู่แล้วทุกเครื่อง (LibreOffice ใช้ค่าของตัวเองแทน ดูแถวด้านล่าง) |
| ไฟล์ที่**สกิลนี้สร้าง** มีเส้นหยักใต้คำไทย เมื่อเปิดในเครื่องคนอื่น | เครื่องนั้นไม่มีภาษาไทยอยู่ในระบบ Word จึงตรวจคำไทยด้วยภาษาอื่น | สร้างใหม่ด้วย `--thai-language` (บอกว่า "ขอให้เป็นไทยแน่นอนทุกเครื่อง") แล้วสระอำจะวางผิดใน WPS Writer |
| ใน LibreOffice Writer มีเส้นหยักใต้คำไทยทุกคำ (แถบสถานะขึ้นว่า Hindi หรือภาษาอื่น) | LibreOffice ไม่เอาภาษาจากเครื่อง แต่ใช้ค่าเริ่มต้นของตัวเองสำหรับการจัดวางอักษรซับซ้อน (complex text layout) ซึ่งในโปรแกรมภาษาอังกฤษคือ Hindi | ไปที่ Tools → Options → Languages and Locales → General แล้วตั้งค่าเริ่มต้นของ complex text layout เป็น Thai ยังไม่ได้วัดว่าการสร้างไฟล์ด้วย `--thai-language` แก้ปัญหานี้ใน LibreOffice ได้หรือไม่ |
| ใน Word มีเส้นหยักแดงใต้โค้ด | โค้ดไม่ใช่คำในภาษาใด เส้นนี้ไม่ออกตอนพิมพ์ | ไม่ต้องแก้ไฟล์ ถ้าต้องการซ่อนบนหน้าจอ ให้สั่ง "ซ่อนเส้นหยัก" (`--hide-spelling-errors`) |
| ใน Google Docs สารบัญเป็นฟอนต์อื่น | Google Docs เปลี่ยนสารบัญเป็นแบบของตัวเอง | ไม่ต้องแก้ไฟล์ Word แสดงตามที่สร้าง |
| ใน Google Docs สารบัญตารางกับสารบัญภาพกลายเป็นรายการหัวข้อ เหมือนสารบัญ | สั่งอัปเดตสารบัญใน Google Docs — มันไม่มีสารบัญตารางและสารบัญภาพของตัวเอง จึงเขียนใหม่เป็นรายการหัวข้อทั้งสามอัน | **อย่าสั่งอัปเดตใน Google Docs** รายการอยู่ในไฟล์อยู่แล้ว อ่านตามที่มาได้เลย ถ้าเขียนทับไปแล้วให้ดาวน์โหลดไฟล์ใหม่ แล้วอัปเดตใน Word, LibreOffice หรือ WPS แทน |
| ใน Word บนเว็บ วรรณยุกต์ลอยสูงเหนือตัวอักษร | Word บนเว็บไม่มีฟอนต์ TH Sarabun New จึงสลับไปใช้ฟอนต์แทนที่วางเครื่องหมายผิด | ถ้าเอกสารจะอ่านหรือแก้บนเว็บ ให้สร้างใหม่ด้วย `--font "TH SarabunPSK"` (บอกว่า "ขอฟอนต์ TH SarabunPSK") ซึ่งมีอยู่ในรายการฟอนต์ของมัน |
| ไฟล์จากที่อื่นมีเส้นหยักใต้คำไทย | ไฟล์ไม่ได้บอก Word ว่าข้อความเป็นภาษาไทย | ตรวจไฟล์ ([สถานการณ์ที่ 13](scenarios.md#สถานการณ์ที่-13-ตรวจไฟล์-word-ที่มีอยู่)) แล้วสร้างใหม่ด้วยสกิล |

หากยังแก้ไม่ได้ [แจ้งที่หน้า Issues](https://github.com/sayam/thai-docx-skill/issues) พร้อมข้อความที่พิมพ์
