## ตอนติดตั้ง

| เจออะไร | เพราะอะไร | ทำอย่างไร |
|---|---|---|
| แอปไม่แสดง thai-docx ในรายการ | วางโฟลเดอร์ผิดที่ หรือซ้อนลึกไปหนึ่งชั้น | ที่อยู่ไฟล์ต้องลงท้าย `skills/thai-docx/SKILL.md` ไม่ใช่ `skills/thai-docx/thai-docx/SKILL.md` แล้วเปิดแอปใหม่ |
| แอป Claude ไม่รับไฟล์ที่อัปโหลด | ยังไม่เปิดการรันโค้ด องค์กรปิดสกิลที่ผู้ใช้สร้างเอง หรือเป็นรุ่น 0.1.0 ซึ่งคำอธิบายสกิลยาวเกินที่แอปรับ | เปิด **Code execution and file creation** ถามผู้ดูแลองค์กร หรือดาวน์โหลดรุ่นที่ใหม่กว่า 0.1.0 ([แอป Claude](install.md#แอป-claude)) ถ้ายังไม่ได้ [แจ้งที่หน้า Issues](https://github.com/sayam/thai-docx-skill/issues) พร้อมข้อความที่ขึ้น |
| แอป Gemini ไม่รับไฟล์ที่อัปโหลด | Google ให้ `SKILL.md` อยู่ในโฟลเดอร์หลักของ zip | zip ของข้างในโฟลเดอร์ `thai-docx` แล้วอัปโหลดใหม่ ([แอป Gemini](install.md#แอป-gemini)) |
| ChatGPT ขึ้นว่า **Needs Review** หรือ **Blocked** | ที่ทำงานตั้งให้ตรวจสกิลที่อัปโหลด | ถามผู้ดูแลระบบของที่ทำงาน |
| ผู้ช่วยบอกว่าไม่มี Python หรือ Node.js หรือสร้างไฟล์ไม่ได้เพราะ Python ผิดพลาด | เครื่องไม่มีทั้งสองอย่าง หรือ Python เก่ากว่า 3.11 | ติดตั้ง Python 3.11 ขึ้นไป หรือ Node.js 22 ขึ้นไป |
| ผู้ช่วยสร้างไฟล์ Word ด้วยวิธีของตัวเอง ไม่ใช้สกิล | ผู้ช่วยไม่ได้เลือกสกิลนี้ | ขึ้นต้นข้อความด้วย `/thai-docx` (Claude Code, Copilot, Cursor), `$thai-docx` (Codex) หรือ "ใช้สกิล thai-docx" |

## ตอนสร้างไฟล์

| เจออะไร | เพราะอะไร | ทำอย่างไร |
|---|---|---|
| มี **คำเตือน (warning)** | ไฟล์สร้างแล้ว แต่มีเรื่องควรดู เช่น ฟอนต์ไม่มีตัวอักษรไทย หรือการตั้งค่าไม่มีผล | อ่านคำเตือน แล้วปรับคำขอถ้าจำเป็น |
| มี **ข้อผิดพลาดที่บรรทัด ...** | Markdown บรรทัดนั้นมีสิ่งที่สกิลไม่รับ เช่น แท็ก HTML ยังไม่สร้างไฟล์ | แก้บรรทัดนั้น แล้วสั่งใหม่ |
| มี **findings** | ข้อบกพร่องของสกิลเอง ยังไม่สร้างไฟล์ | ช่วยแจ้งที่หน้า [Issues](https://github.com/sayam/thai-docx-skill/issues) |
| รูปใช้ไม่ได้ | ไม่ใช่ PNG หรือ JPEG, เป็นรูปจากอินเทอร์เน็ต หรืออยู่นอกโฟลเดอร์ของไฟล์ Markdown | ใช้ PNG หรือ JPEG ในโฟลเดอร์นั้น หรือบอกว่ารูปอยู่โฟลเดอร์ไหน |
| การตั้งค่าที่ขอไม่อยู่ในคำตอบ | ผู้ช่วยตกหล่น | ขอการตั้งค่านั้นอีกครั้ง |
| ผู้ช่วยไม่ถามคำถาม | ข้อความไม่มีคำว่า `thai-docx grill` (มีขีดกลาง) | ส่งใหม่ให้มีคำนี้ |
| `'' is not a question` | มีช่องว่างหลังจุลภาค เช่น `เฉพาะ size, toc` | เขียนติดกัน `เฉพาะ size,toc` |
| แอปแชตหาโปรไฟล์ที่บันทึกไว้ไม่เจอ | แอปแชตลืมไฟล์เมื่อจบแชต | แนบไฟล์ `.json` ของโปรไฟล์ |
| บันทึกโปรไฟล์แล้วต้องขออนุญาต หรือบันทึกไม่ได้ | แอปไม่ให้ผู้ช่วยเขียนไฟล์นอกโปรเจกต์ | กดอนุญาต หรือพูดว่า "บันทึกไว้ในโปรเจกต์นี้" |

## ตอนเปิดไฟล์

| เจออะไร | เพราะอะไร | ทำอย่างไร |
|---|---|---|
| ตัวอักษรไทยเป็นฟอนต์แปลก | เครื่องไม่มีฟอนต์ที่ไฟล์ใช้ | ติดตั้งฟอนต์นั้น หรือขอฟอนต์ที่เครื่องมี |
| สารบัญหรือสารบัญตารางไม่มีเลขหน้า | ยังไม่ได้อัปเดตฟิลด์ | Word: กด Ctrl+A แล้ว F9 · LibreOffice: Ctrl+Shift+F9 · WPS: **References > Update** |
| ใน WPS Writer เลข บทที่ หรือ ภาคผนวก เป็นตัวอักษรแปลก หรือ ำ อยู่ผิดที่ | ข้อจำกัดของ WPS Writer ไฟล์ถูกต้อง | เปิดด้วย Word, LibreOffice หรือ Google Docs |
| ใน Google Docs สารบัญเป็นฟอนต์อื่น | Google Docs เปลี่ยนสารบัญเป็นแบบของตัวเอง | ไม่ต้องแก้ไฟล์ Word แสดงตามที่สร้าง |
| ไฟล์จากที่อื่นมีเส้นหยักใต้คำไทย | ไฟล์ไม่ได้บอก Word ว่าข้อความเป็นภาษาไทย | ตรวจไฟล์ ([สถานการณ์ที่ 13](scenarios.md#สถานการณ์ที่-13-ตรวจไฟล์-word-ที่มีอยู่)) แล้วสร้างใหม่ด้วยสกิล |
