# สถานการณ์การใช้งาน

แต่ละสถานการณ์คืองานหนึ่งอย่าง บอกว่าพิมพ์อะไร และจะได้อะไร สิ่งที่พิมพ์เหมือนกันทุกแอป
ถ้าแอปไหนต่างไป สถานการณ์นั้นจะบอกไว้ ติดตั้งสกิลก่อน: [ติดตั้งและเริ่มใช้](install.md)

[หน้าแรกของคู่มือ](../th.md) · [English](../en/scenarios.md)

ในแอปแชต (Claude บนเว็บ, ChatGPT, Gemini) คำว่า "วางไฟล์ไว้ในโฟลเดอร์" หมายถึง **แนบไฟล์ในแชต**
และไฟล์ Word ที่ได้ให้ **กดดาวน์โหลดในแชต**

---

## สถานการณ์ที่ 1: ขอแบบง่ายที่สุด

**ใช้เมื่อ** อยากได้เอกสารเร็ว ๆ ยังไม่สนใจเรื่องรูปแบบ

1. บอกว่าอยากได้เอกสารเรื่องอะไร

   ```text
   ช่วยทำไฟล์ Word สรุปวิธีขอหนังสือเดินทางแบบสั้น ๆ มีหัวข้อ รายการเอกสารที่ต้องใช้ และตารางค่าธรรมเนียม
   ```

2. ผู้ช่วยเขียนเนื้อหา แล้วสร้างไฟล์ทันที **ไม่ถามอะไรก่อน**
3. ผู้ช่วยบอกชื่อไฟล์และการตั้งค่า เช่น

   > สร้าง `passport.docx` แล้ว — ฟอนต์ TH Sarabun New 16 pt, กระดาษ A4, ขอบซ้าย 1.5 นิ้ว
   > ด้านอื่น 1 นิ้ว ปรับค่าใดก็ได้

การตั้งค่าเริ่มต้น (ถ้าไม่ได้ขออะไร)

| เรื่อง | ค่าเริ่มต้น |
|---|---|
| ฟอนต์ | TH Sarabun New ขนาด 16 pt |
| กระดาษ | A4 แนวตั้ง |
| ขอบกระดาษ | ซ้าย 1.5 นิ้ว ด้านอื่น 1 นิ้ว |
| ระยะบรรทัด | 1 เท่า |
| การจัดย่อหน้า | ชิดซ้าย |
| สารบัญ, เลขหน้า | ไม่มี |

## สถานการณ์ที่ 2: มีไฟล์ Markdown อยู่แล้ว

**ใช้เมื่อ** เขียนเนื้อหาไว้เองแล้ว อยากได้เป็นไฟล์ Word

1. วางไฟล์ เช่น `report.md` ไว้ในโฟลเดอร์
2. พิมพ์

   ```text
   ช่วยทำ report.md เป็นไฟล์ Word ชื่อ report.docx
   ```

3. ผู้ช่วยใช้ไฟล์ของเรา **ตามที่เขียนไว้ทุกตัวอักษร** แล้วสร้าง `report.docx`

สิ่งที่เขียนใน Markdown ได้

```markdown
# หัวข้อใหญ่

## หัวข้อย่อย

ข้อความธรรมดา **ตัวหนา** *ตัวเอียง* ~~ขีดฆ่า~~ `โค้ด` <u>ขีดเส้นใต้</u> H<sub>2</sub>O x<sup>2</sup>
<kbd>Ctrl</kbd> [ลิงก์](https://example.com) และขึ้นบรรทัดใหม่<br>ตรงนี้

- รายการ
  - รายการย่อย

1. รายการแบบมีเลข

- [x] งานที่ทำเสร็จแล้ว
- [ ] งานที่ยังไม่ได้ทำ

| สินค้า | ราคา |
|---|--:|
| ปากกา | 10 |

> ข้อความที่ยกมา

~~~
โค้ด ตามที่เขียน
~~~

---

เชิงอรรถ[^1]

[^1]: ข้อความเชิงอรรถ

![ภาพประกอบ](chart.png)
```

ข้อควรรู้

- รูปต้องเป็น PNG หรือ JPEG อยู่ในโฟลเดอร์เดียวกับไฟล์ Markdown หรือโฟลเดอร์ย่อย
  ถ้ารูปอยู่โฟลเดอร์อื่น ให้บอกผู้ช่วยว่าอยู่ที่ไหน
- เขียนภาษาไทยตามปกติ **อย่าเว้นวรรคระหว่างคำ** ขึ้นบรรทัดใหม่กลางประโยคไทยได้ คำจะต่อกันเหมือนเดิม
- บรรทัด `title:` และ `author:` ที่อยู่บนสุดของไฟล์ ระหว่างเส้น `---` จะเป็นชื่อเรื่องและชื่อผู้เขียนในข้อมูลของไฟล์
- สูตรคณิตศาสตร์ เช่น `$x^2$` จะเป็นข้อความธรรมดา และมีคำเตือน
- แท็ก HTML อื่นใช้ไม่ได้ ถ้ามี ผู้ช่วยจะบอกว่า **อยู่บรรทัดไหน** และยังไม่สร้างไฟล์ ให้แก้บรรทัดนั้นแล้วสั่งใหม่
- รายการทั้งหมด: [references/markdown.md](https://github.com/sayam/thai-docx-skill/blob/main/skills/thai-docx/references/markdown.md)

## สถานการณ์ที่ 3: เปลี่ยนการตั้งค่า

**ใช้เมื่อ** ได้ไฟล์แล้ว แต่อยากได้ฟอนต์ ขนาด กระดาษ หรือเลขหน้าแบบอื่น

1. พิมพ์สิ่งที่อยากเปลี่ยนในแชตเดิม

   ```text
   ขอฟอนต์ Sarabun ขนาด 14 และใส่เลขหน้าตรงกลางด้านล่าง
   ```

2. ผู้ช่วยสร้างไฟล์ใหม่ เปลี่ยนเฉพาะที่ขอ
3. ตรวจการตั้งค่าในคำตอบของผู้ช่วย

สิ่งที่ขอได้

| อยากได้ | พูดว่า |
|---|---|
| ฟอนต์อื่น | "ขอฟอนต์ Sarabun" |
| ขนาดตัวอักษรอื่น | "ขนาด 14" |
| กระดาษ Letter หรือ F14 | "ใช้กระดาษ F14" |
| กระดาษแนวนอน | "ขอแนวนอน" |
| ขอบกระดาษแบบอื่น | "ขอบ 1 นิ้วทุกด้าน" |
| ย่อหน้าบรรทัดแรก | "ย่อหน้า 0.5 นิ้ว" (เฉพาะย่อหน้าเนื้อความ) |
| บรรทัดห่างขึ้น | "ระยะบรรทัด 1.5" (โค้ดและเชิงอรรถยังห่าง 1 เท่า) |
| จัดข้อความเต็มบรรทัดแบบไทย | "จัดกระจายแบบไทย" (ย่อหน้าที่ไม่มีภาษาไทยยังชิดซ้าย) |
| สารบัญ | "ใส่สารบัญ" |
| เลขหัวข้อ (1. 1.1 1.1.1) | "ใส่เลขหัวข้อ" |
| เลขหน้า | "ใส่เลขหน้า" (มุมขวาบน), "เลขหน้ากลางบน" หรือ "เลขหน้ากลางล่าง" |
| หน้าแรกไม่มีเลขหน้า | "หน้าแรกไม่ต้องมีเลขหน้า" |
| ข้อความหัวกระดาษหรือท้ายกระดาษ | "หัวกระดาษเขียนว่า ลับ", "ท้ายกระดาษเขียนว่า ร่าง" |
| เลขไทย (๑ ๒ ๓) | "ใช้เลขไทย" (เฉพาะเลขที่สกิลใส่ให้ เช่น เลขหน้า เลขหัวข้อ เลขรายการ เลขตาราง เลขเชิงอรรถ ตัวเลขที่เราพิมพ์ไม่เปลี่ยน) |
| ไม่มีเส้นหยัก | "ซ่อนเส้นหยัก" (คำที่สะกดผิดจริงก็จะไม่มีเส้นหยักด้วย) |
| หัวตารางไม่ซ้ำทุกหน้า | "ไม่ต้องทำซ้ำหัวตาราง" |
| คอลัมน์ตารางกว้างตามข้อความ | "ให้คอลัมน์ตารางกว้างตามข้อความ" |
| ตัวอักษรในตารางเล็กลง | "ตัวอักษรในตารางขนาด 14" |

การตั้งค่าทั้งหมด: [references/settings.md](https://github.com/sayam/thai-docx-skill/blob/main/skills/thai-docx/references/settings.md)
ถ้าขอสิ่งที่เอกสารไม่มี เช่น ตั้งค่าตารางแต่ไม่มีตาราง ผู้ช่วยจะบอกว่าการตั้งค่านั้นไม่มีผล

## สถานการณ์ที่ 4: บอกการตั้งค่าตั้งแต่แรก

**ใช้เมื่อ** รู้อยู่แล้วว่าอยากได้แบบไหน

1. ใส่การตั้งค่าไว้ในคำขอเลย

   ```text
   ทำ input.md เป็นไฟล์ Word ชื่อ output.docx ขนาดตัวอักษร 14 กระดาษ letter ขอบทุกด้าน 1 นิ้ว ย่อหน้าบรรทัดแรก 0.5 นิ้ว ระยะบรรทัด 1.5
   ```

2. ผู้ช่วยสร้างไฟล์ทันที แล้วบอกการตั้งค่าที่ใช้
3. **ตรวจว่ามีครบทุกข้อที่ขอ** ถ้าขาดข้อไหน ให้บอกซ้ำ

## สถานการณ์ที่ 5: ให้ผู้ช่วยถามก่อน

**ใช้เมื่อ** ยังไม่แน่ใจว่าจะตั้งค่าอย่างไร อยากเลือกจากตัวเลือก (โหมด grill)

1. ใส่คำว่า **`thai-docx grill`** (มีขีดกลาง) ไว้ในข้อความ ใส่ไว้ต้นข้อความจะง่ายที่สุด
   ถ้าไม่มีคำนี้ ผู้ช่วยจะไม่ถาม

   ```text
   thai-docx grill ช่วยทำเอกสาร Word เรื่องกำหนดการประชุมทีมประจำเดือนให้หน่อย
   ```

2. ผู้ช่วยถาม 9 ข้อ แต่ละข้อมี 2 ถึง 4 ตัวเลือก (a ถึง d): ฟอนต์, ขนาดตัวอักษร, กระดาษและขอบ,
   การจัดข้อความ (ชิดซ้ายหรือกระจาย), ย่อหน้าบรรทัดแรก, สารบัญ, เลขหน้า, เส้นหยัก และจะบันทึกเป็นโปรไฟล์ไหม
3. ตอบคำถาม
   - ใน Claude Code กดเลือกได้เลย
   - แอปอื่น ตอบเป็นเลขข้อกับตัวอักษร ข้อที่ไม่ตอบใช้ตัวเลือกเดิม

   ```text
   4b 7b ที่เหลือใช้ค่าเดิม
   ```

4. ผู้ช่วยสร้างไฟล์ตามคำตอบ

ถ้าพิมพ์ `thai-docx grill` แล้ว ผู้ช่วยยังสร้างไฟล์เลยโดยไม่ถาม ให้ส่งข้อความเดิมอีกครั้ง

## สถานการณ์ที่ 6: แต่งหัวข้อ

**ใช้เมื่อ** อยากให้หัวข้อมีสี ขนาด หรือตำแหน่งของตัวเอง

1. บอกว่าอยากได้หัวข้อแบบไหน

   ```text
   ทำ notice.md เป็นไฟล์ Word หัวข้อใหญ่สุดสีน้ำเงินเข้ม จัดกึ่งกลาง ขนาด 22 pt หัวข้อรองขีดเส้นใต้คู่
   ```

2. ผู้ช่วยเขียนการตั้งค่าหัวข้อไว้บนสุดของไฟล์ Markdown แบบนี้

   ```markdown
   ---
   heading-1: font-size: 22pt; color: #1F4E79; text-align: center
   heading-2: text-decoration: underline double
   ---
   ```

3. เลขหัวข้อ เช่น "บทที่ 1" หรือ "1.1" ได้ฟอนต์ ขนาด และสีเดียวกับหัวข้อ

ขออย่างอื่นได้อีก เช่น ฟอนต์ ตัวหนา ตัวเอียง ขีดฆ่า ขีดเส้นใต้แบบจุด ขีด หรือคลื่น
จัดเต็มบรรทัดหรือกระจายแบบไทย ระยะเยื้องซ้ายหรือย่อหน้าแบบห้อย ระยะก่อนและหลังหัวข้อ ระยะบรรทัด
หรือขึ้นหน้าใหม่ก่อนหัวข้อ:
[references/heading-styles.md](https://github.com/sayam/thai-docx-skill/blob/main/skills/thai-docx/references/heading-styles.md)

## สถานการณ์ที่ 7: รายงานหรือวิทยานิพนธ์

**ใช้เมื่อ** เอกสารมีหน้าปก ส่วนหน้า บทต่าง ๆ ตาราง รูป และภาคผนวก

1. บอกสิ่งที่เอกสารต้องมีให้ครบ

   ```text
   ช่วยทำ draft.md เป็นไฟล์ Word วิทยานิพนธ์ชื่อ thesis.docx มีหน้าปก บทคัดย่อ สารบัญ สารบัญตาราง บทที่มีเลขบท ชื่อตารางแบบ ตารางที่ 1-1 ภาคผนวก ก ข ค และเลขหน้า ห้ามแก้เนื้อหา
   ```

2. ผู้ช่วยใส่ **ป้ายบอกส่วน** ลงในไฟล์ Markdown ป้ายเหล่านี้ไม่แสดงในไฟล์ Word

   | ป้าย | ความหมาย |
   |---|---|
   | `<!-- front -->` | ส่วนหน้า เช่น บทคัดย่อ (เลขหน้า ก ข ค) |
   | `<!-- chapters -->` | ส่วนเนื้อหา หัวข้อ `#` เป็น "บทที่ 1", "บทที่ 2" |
   | `<!-- back -->` | ส่วนท้าย เช่น บรรณานุกรม |
   | `<!-- appendices -->` | ภาคผนวก หัวข้อ `#` เป็น "ภาคผนวก ก", "ภาคผนวก ข" |
   | `<!-- toc -->` | ตรงนี้ใส่สารบัญ |
   | `<!-- list-of-tables -->` | ตรงนี้ใส่สารบัญตาราง |
   | `<!-- list-of-figures -->` | ตรงนี้ใส่สารบัญภาพ |

3. ชื่อตารางเขียน `Table: ชื่อตาราง` เป็นบรรทัด **ก่อนตาราง** ชื่อรูปเขียน `Figure: ชื่อรูป`
   เป็นบรรทัด **หลังรูป** เว้นบรรทัดว่างคั่นหนึ่งบรรทัด ใน Word จะเป็น "ตารางที่ 1-1 ชื่อตาราง"
   และ "รูปที่ 1-1 ชื่อรูป"
4. สารบัญ สารบัญตาราง และสารบัญภาพ มีรายการให้ทันที ส่วนเลขหน้าจะมาหลังอัปเดตฟิลด์
   Word บนคอมพิวเตอร์จะถามให้อัปเดตตอนเปิดไฟล์ (หรือกด Ctrl+A แล้วกด F9)
   LibreOffice กด Ctrl+Shift+F9 ส่วน WPS ไปที่ **References > Update**

ขออย่างอื่นได้อีก

| อยากได้ | พูดว่า |
|---|---|
| เลขหัวข้อย่อย: 1.1 ในบท, ก.1 ในภาคผนวก | "ใส่เลขหัวข้อ" |
| ใช้คำอื่นแทน บทที่ | "ใช้คำว่า บท แทน บทที่" |
| ใช้คำอื่นแทน ตารางที่ หรือ รูปที่ | "ใช้คำว่า ตาราง แทน ตารางที่", "ใช้คำว่า ภาพที่ แทน รูปที่" |
| เลขหน้าส่วนหน้าเป็น i ii iii, I II III หรือ 1 2 3 | "เลขหน้าส่วนหน้าเป็นเลขโรมันตัวเล็ก" |
| ใช้คำอื่นแทน ภาคผนวก | "ใช้คำว่า Appendix แทน ภาคผนวก" |
| ภาคผนวกเป็น A B C, 1 2 3 หรือ I II III | "ภาคผนวกใช้ A B C" |
| หน้าแรกของแต่ละส่วนไม่มีเลขหน้า | "หน้าแรกไม่ต้องมีเลขหน้า" |
| บทที่ 1 อยู่บรรทัดหนึ่ง ชื่อบทอยู่บรรทัดถัดไป | "ให้ชื่อบทขึ้นบรรทัดใหม่" |

ข้อควรรู้

- ส่วนที่อยู่ก่อนป้ายแรกคือหน้าปก หัวข้อ `#` ทุกหัวข้อขึ้นหน้าใหม่
- ป้ายต้องเรียงตามลำดับนี้ อย่างละครั้ง: front, chapters, back, appendices, back ถ้าสลับลำดับ
  จะสร้างไฟล์ไม่ได้ และสกิลจะบอกบรรทัด
- ส่วนหน้ามีเลขหน้า ก ข ค เมื่อขอเลขหน้าด้วยเท่านั้น
- ตารางที่อยู่นอกบท ชื่อจะเป็น "ตารางที่ 1"
- ป้าย `<!-- toc -->` ใส่สารบัญให้แล้ว ถ้าขอ "ใส่สารบัญ" อีก จะได้สารบัญสองชุด

## สถานการณ์ที่ 8: บันทึกเป็นโปรไฟล์

**ใช้เมื่อ** ได้การตั้งค่าที่ชอบแล้ว อยากใช้อีกโดยไม่ต้องบอกซ้ำ

**วิธีที่ 1: ตอนตอบคำถาม grill** ข้อสุดท้ายถามว่าจะบันทึกไหม ตอบ b (ใช้ได้ทุกโปรเจกต์) หรือ c
(เฉพาะโปรเจกต์นี้) แล้วตั้งชื่อ

```text
1c 9b ชื่อ myreport
```

**วิธีที่ 2: บอกตรง ๆ**

```text
บันทึกการตั้งค่านี้เป็นโปรไฟล์ชื่อ thesis: ขนาด 15 จัดกระจายแบบไทย ใส่เลขหน้ากลางล่าง
```

โปรไฟล์ไปอยู่ที่ไหน

- **บนเครื่องของเรา** (Claude Code, Codex, Copilot, Cursor และเอเจนต์เขียนโค้ดอื่น ๆ):
  `~/.thai-docx/profiles/ชื่อ.json` ใช้ได้ทุกโปรเจกต์ ถ้าพูดว่า "บันทึกไว้ในโปรเจกต์นี้"
  จะเก็บใน `.thai-docx/profiles/` ของโปรเจกต์แทน
- **ในแอปแชต** (Claude บนเว็บ, ChatGPT, Gemini): ได้ไฟล์ `.json` มา **เก็บไว้เอง**
  แล้วแนบมาครั้งหน้า

ชื่อโปรไฟล์ใช้ตัวอักษร ตัวเลข `-` หรือ `_` ได้ ห้ามมีช่องว่าง

ข้อควรรู้

- ถ้าบันทึกด้วยชื่อที่มีอยู่แล้ว โปรไฟล์เดิมจะถูกแทนที่ ถ้าอยากเก็บโปรไฟล์เดิมไว้ ให้ตั้งชื่อใหม่

## สถานการณ์ที่ 9: ใช้โปรไฟล์

1. พิมพ์ชื่อโปรไฟล์ในคำขอ ถ้าเป็นแอปแชต ให้แนบไฟล์ `.json` ด้วย

   ```text
   ทำ chapter2.md เป็นไฟล์ Word ใช้โปรไฟล์ thesis
   ```

2. ผู้ช่วยสร้างไฟล์ด้วยโปรไฟล์นั้น แล้วบอกว่าใช้โปรไฟล์ไหน
3. อยากเปลี่ยนบางอย่างแค่ครั้งนี้ ก็บอกเพิ่ม สิ่งที่บอกเพิ่มชนะโปรไฟล์

   ```text
   ใช้โปรไฟล์ thesis แต่ครั้งนี้ขอขนาด 18
   ```

หรือเอาบางอย่างออก เฉพาะไฟล์นี้

```text
ใช้โปรไฟล์ thesis แต่ไม่เอาสารบัญ
```

ไฟล์โปรไฟล์ใช้จากที่อยู่ของไฟล์ได้เลย เช่น `profiles/thesis.json` ไม่ต้องนำเข้าก่อน

ดูว่ามีโปรไฟล์อะไรบ้าง และในโปรไฟล์มีอะไร

```text
มีโปรไฟล์ thai-docx อะไรบ้าง แล้ว thesis ตั้งค่าอะไรไว้
```

## สถานการณ์ที่ 10: แบ่งปันโปรไฟล์

**ส่งให้คนอื่น**

1. พิมพ์

   ```text
   ส่งออกโปรไฟล์ thesis เป็นไฟล์ให้หน่อย
   ```

2. จะได้ไฟล์ `thesis.json` ส่งทางไหนก็ได้ เช่น อีเมล LINE ไดรฟ์ที่แชร์กัน

**รับจากคนอื่น**

1. วางไฟล์ `.json` ไว้ในโฟลเดอร์
2. พิมพ์

   ```text
   นำเข้าโปรไฟล์จากไฟล์ thesis.json
   ```

3. อยากตั้งชื่อใหม่ ให้บอกไปด้วย เช่น "นำเข้าเป็นชื่อ school-thesis"

สกิลตรวจไฟล์ก่อนเสมอ ไฟล์โปรไฟล์มีได้แค่การตั้งค่า ถ้ามีอย่างอื่นจะไม่รับ ถ้าพูดว่า
"นำเข้าไว้ในโปรเจกต์นี้" จะใช้ได้เฉพาะโปรเจกต์นั้น และโปรไฟล์ของโปรเจกต์ชนะโปรไฟล์ชื่อเดียวกันในโฟลเดอร์บ้าน

## สถานการณ์ที่ 11: แก้โปรไฟล์ด้วยคำถาม

**ใช้เมื่อ** อยากปรับโปรไฟล์ที่มีอยู่ แล้วบันทึกเป็นชื่อใหม่ ของเดิมยังอยู่

1. พิมพ์ `thai-docx grill จาก` ชื่อเดิม `บันทึกเป็น` ชื่อใหม่

   ```text
   thai-docx grill จาก thesis บันทึกเป็น thesis-v2 ช่วยทำ input.md เป็นไฟล์ Word ชื่อ output.docx
   ```

   ใช้คำภาษาอังกฤษก็ได้

   ```text
   thai-docx grill from thesis save to thesis-v2
   ```

2. ผู้ช่วยถามเหมือนสถานการณ์ที่ 5 (ไม่มีข้อถามว่าจะบันทึกไหม) โดยตัวเลือกที่ตรงกับโปรไฟล์เดิมมีป้าย "(ตอนนี้)"
3. ตอบเฉพาะข้อที่อยากเปลี่ยน

   ```text
   2b 6a ที่เหลือเหมือนเดิม
   ```

4. ผู้ช่วยบันทึก `thesis-v2` แล้วสร้างไฟล์ด้วยโปรไฟล์นั้น

อยากให้ถามแค่บางข้อ ใช้คำว่า `เฉพาะ` ตามด้วยชื่อข้อ คั่นด้วยจุลภาค (,) ไม่เว้นวรรค

```text
thai-docx grill จาก thesis บันทึกเป็น thesis-v3 เฉพาะ size,toc
```

ชื่อข้อ: `font` (ฟอนต์), `size` (ขนาด), `paper` (กระดาษและขอบ), `align` (การจัดข้อความ),
`indent` (ย่อหน้าบรรทัดแรก), `toc` (สารบัญ), `page-numbers` (เลขหน้า), `squiggles` (เส้นหยัก),
`save` (บันทึก) หรือใช้เลขข้อ 1 ถึง 9

ข้อควรรู้

- `จาก`, `บันทึกเป็น`, `เฉพาะ` ต้องอยู่ **ต่อจาก `thai-docx grill` ทันที**
- ถ้าไม่มีโปรไฟล์ชื่อนั้น ผู้ช่วยจะบอกว่าไม่พบ

## สถานการณ์ที่ 12: แก้โปรไฟล์ด้วยประโยคเดียว

**ใช้เมื่อ** รู้แน่แล้วว่าจะเปลี่ยนอะไร

```text
สร้างโปรไฟล์ thesis-v2 จากโปรไฟล์ thesis แต่เปลี่ยนเป็นขนาด 14 และไม่เอาสารบัญ
```

โปรไฟล์ใหม่เหมือนเดิมทุกอย่าง ยกเว้นสิ่งที่บอก คำว่า "ไม่เอาสารบัญ" หรือ "ไม่เอาเลขหน้า"
จะคืนการตั้งค่านั้นเป็นค่าเริ่มต้น

## สถานการณ์ที่ 13: ตรวจไฟล์ Word ที่มีอยู่

**ใช้เมื่อ** มีไฟล์ Word ภาษาไทยจากที่อื่น แล้วมีเส้นหยัก ตัดบรรทัดแปลก หรือตัวหนาไม่หนา

1. วางไฟล์ไว้ในโฟลเดอร์
2. พิมพ์

   ```text
   ช่วยตรวจ report.docx หน่อยว่าทำไมมีเส้นหยักแดงใต้คำไทยทุกคำ
   ```

3. ผู้ช่วยอธิบายว่าเจอปัญหาอะไร และแต่ละปัญหาทำให้ไฟล์เป็นอย่างไร

สกิล **ตรวจอย่างเดียว ไม่ซ่อมไฟล์** ถ้ามีเนื้อหาอยู่ ให้สร้างไฟล์ใหม่ด้วยสถานการณ์ที่ 1 หรือ 2
